# Getting Support for Indicative

- **Documentation & Guides:** Start with [README.md](README.md), [Architecture Docs](docs/architecture/system-architecture.md), and [CI/CD Security Rules](rules/cicd/github-actions/README.md).
- **Bug Reports & Feature Proposals:** Open a GitHub Issue using the structured templates under `.github/ISSUE_TEMPLATE/`.
- **Security Vulnerabilities:** **Do not open a public issue.** Follow [SECURITY.md](SECURITY.md) for private coordinated disclosure.
- **Contributing Rules & Fixes:** Read [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/community/README.md](docs/community/README.md).
